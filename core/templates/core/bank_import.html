Імпорт банківської виписки CSV

Імпорт додає записи до управлінського журналу. Він не підтверджує реальний баланс банку, не створює бухгалтерські проводки та не прив'язує автоматично платежі до продажів, закупівель чи авансів.

Формат CSV

Файл UTF-8 або UTF-8 із BOM. Заголовки можуть бути українською або англійською.

ПолеОбов'язковеПриклад
date / ДатаТак2026-11-18 або 18.11.2026

note / ПриміткаНіКоментар

Напрямки: income / надходження / credit; expense / списання / debit.

Повторний імпорт однакової операції з тим самим рахунком, датою, напрямком, сумою, контрагентом і призначенням буде пропущено. Якщо банк має унікальний ID операції, його поки слід включати до призначення/примітки, щоб не змішувати схожі платежі.
