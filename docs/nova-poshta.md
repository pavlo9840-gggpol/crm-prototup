# Інтеграція Нової пошти

Розділ **Замовлення → Відправлення Нової пошти** зберігає чернетки, створює експрес-накладні та оновлює статус за номером ТТН.

## Налаштування сервера

Налаштуйте секрети в середовищі процесу Django (не в Git, не в шаблонах і не в браузері):

- `NOVA_POSHTA_API_KEY` — API-ключ бізнес-кабінету.
- `NP_SENDER_CITY_REF` — Ref міста відправника.
- `NP_SENDER_REF` — Ref контрагента відправника.
- `NP_SENDER_ADDRESS_REF` — Ref відділення відправника.
- `NP_SENDER_CONTACT_REF` — Ref контактної особи відправника.
- `NP_SENDER_PHONE` — телефон відправника у форматі, який приймає API.

Використовується серверний endpoint `https://api.novaposhta.ua/v2.0/json/`. API може повертати HTTP 200 навіть за невдалого запиту — код перевіряє поле `success` у JSON-відповіді.

## Робочий процес

1. Створіть чернетку й заповніть одержувача, телефон, місто, відділення, вагу та оголошену вартість.
2. Для створення ТТН потрібні точні Ref міста й відділення з довідника Нової пошти. Звичайна назва міста не замінює Ref.
3. Натисніть **Створити ТТН** лише коли дані перевірені. Це реальна операція в API, не тестовий перегляд.
4. Після появи ТТН натискайте **Оновити статус** для актуалізації статусу доставки.

Якщо API-ключ або параметри відправника не налаштовані, система залишає відправлення чернеткою й показує помилку; успішна ТТН не імітується. Перевірте документацію та параметри бізнес-кабінету перед використанням на реальних посилках.

Офіційна довідка: https://novaposhta.ua/for-business/cooperation/integration/
